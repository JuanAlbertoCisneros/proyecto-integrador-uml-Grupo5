# proyecto-integrador-uml-Grupo5

El objetivo es realizar un encargo para resolver un problema organizacional usando el diseño de un sistema, tras analizar la consultora de un instituto de educación superior, esta resolución comprendiendo un problema, identificando requisitos; modelando una solución mediante UML propondrá una arquitectura, y diseñará la persistencia de datos.

### Objetivo y alcance.
Los alcances son los dominios de bases de datos entre los estudiantes participantes, los programa y servicios a utilizar (StarUML, Word, Github),
